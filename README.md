# Дашборд «Март-Трейд» для Vercel

Готовый Next.js-проект. Основной источник — технические листы Google Sheets; встроенный снимок Excel используется только как резерв, если Google API временно недоступен.

## Локальный запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

Откройте `http://localhost:3000`.

## Публикация

1. Создайте приватный репозиторий GitHub и загрузите в него содержимое этой папки.
2. В Vercel выберите **Add New → Project** и импортируйте репозиторий.
3. В **Settings → Environment Variables** добавьте переменные из `.env.example`.
4. Нажмите **Deploy**.

## Google Sheets

1. В Google Cloud включите Google Sheets API и создайте сервисный аккаунт.
2. Откройте доступ к таблице для email сервисного аккаунта с ролью «Читатель».
3. Перенесите `client_email` и `private_key` из JSON-ключа в переменные Vercel.
4. Проверьте `https://ваш-домен.vercel.app/api/dashboard?end=2026-08-24`.

Ключ JSON и `.env.local` нельзя добавлять в GitHub. Сервер читает технические листы `ДДС недельный - по статьям`, `техн.лист плита - заказы`, `дебиторка (расчет)`, `Кредиторка по Заводу (1с)`, `Техн.лист (кошелек)` и `техн рс остатки`. При смене периода интерфейс заново получает актуальные данные и пересчитывает показатели.

## Ограничение доступа

Самый быстрый вариант — включить **Deployment Protection** в настройках проекта Vercel. Для персональных учётных записей сотрудников подключите Clerk/Auth0 и защитите одновременно страницу и `/api/google-sheets`.
